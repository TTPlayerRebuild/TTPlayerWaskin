## 修复说明

原生列表在 `ShowPlaylistContextMenu` 中完成资源位置裁剪、默认项设置和退役服务清理；插件的 `ShowSkinPluginPlaylistMenu` 单独加载资源，仅调用 `PreparePlaylistMenu`。因此主程序更新后，插件仍保留“网络歌曲举报”，并且普通文件错误保留光盘查询项，URL/多选的本地文件操作也未按原生规则裁剪。

本轮将曲目／空白区菜单构造抽取为宿主共用的 `CreatePlaylistFilesMenu`，使用相同的本地化资源、单曲/多选模板、播放默认项、URL 操作与 CDA/CUE 限定。退役命令清理统一在资源裁剪之后、owner-draw 记录创建之前执行，避免删除顺序改变资源位置含义。

空白区保留原生七组菜单的默认状态，仅调整禁止删除文件策略；插件菜单进入和退出时清除目录菜单上下文，避免上次目录操作污染曲目命令。DLL 仍只负责命中、选择与延迟发送菜单请求。

修复位于 `rebuild` 的宿主桥接层。插件 C ABI、标题区、MAKI VM 和 WAL 控件支持范围均未扩展。重新构建当前插件，采用 `0aa4150` 已加入的 Release 体积优化；需要配合更新主程序。
